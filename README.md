# 🚆 Train Booking Platform

## 📌 Project Overview
The Train Booking Platform is a software application designed to simplify the train ticket booking process. It allows users to search for trains, check availability, and book tickets easily. The project aims to provide a convenient and user-friendly railway reservation experience.

## ✨ Features
- 🔍 Search for available trains
- 🎫 Book train tickets
- 👤 Manage passenger details
- 📋 View booking information
- ❌ Cancel tickets
- 🗂️ Manage train and reservation records

## 🛠️ Technologies Used
- **Programming Language:** Java
- **Database:** MySQL
- **IDE:** Eclipse
- **SQL:** For storing and managing booking data

## ⚙️ Installation and Setup
1. Clone or download this repository.
2. Open the project in Eclipse IDE.
3. Configure the MySQL database connection.
4. Create the required database and tables.
5. Update the database credentials in the project configuration.
6. Run the main Java class to start the application.

## 🎯 Project Objectives
- Simplify the train reservation process.
- Manage passenger and train information efficiently.
- Store booking details securely in a database.
- Improve understanding of Java programming and database connectivity.
